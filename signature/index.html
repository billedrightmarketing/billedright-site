Email Signatures

Find your name below and click Copy. Then, in Outlook:
  1. Go to File → Options → Mail → Signatures.
  2. Click New, give it a name, then click OK.
  3. Click inside the signature editor box and paste (Ctrl+V).
  4. Set it as your default signature for new messages and replies, then click OK.
Not working? Click Open instead, select all in the page (Ctrl+A), copy (Ctrl+C), then paste into the signature editor.
